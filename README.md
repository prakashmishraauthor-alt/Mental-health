# Aura Blog

A responsive GitHub Pages-ready blog homepage based on the supplied reference screenshot.

## Structure
- `index.html` — page structure and sample posts
- `style.css` — complete visual design and responsive layout
- `script.js` — theme toggle and newsletter interaction

## Layout
1. Reference-inspired rounded navbar
2. Hero section
3. Category + newsletter sidebar
4. Latest Posts — 3 cards in one row
5. Popular Posts — 3 cards in one row
6. Footer

## Customize
Replace the Unsplash image URLs in `index.html` with your own post/hero images. Edit post titles, descriptions, categories and counts directly in the HTML.

The navbar uses **DM Sans** as the changed navigation font, while the logo remains decorative and the hero/post headings use **Playfair Display**.
